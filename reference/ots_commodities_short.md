# OTS Commodities Short

Official commodity names from the Harmonized System rev 2012 (HS12, four
digits detail).

## Usage

``` r
ots_commodities_short
```

## Format

A data frame with 1,225 observations on the following 2 variables

- `commodity_code`:

  HS four digits commodity code (e.g. 0101)

- `commodity_fullname_english`:

  HS four digits commodity names (e.g. 'Horses, asses, mules and
  hinnies; live')
