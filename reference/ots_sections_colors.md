# OTS Sections Colors

Unofficial colors to ease visualization for the sections in the
Harmonized System rev 2012 (HS12).

## Usage

``` r
ots_sections_colors
```

## Format

A data frame with 22 rows and 2 variables

- `section_code`:

  HS section code (e.g. '01')

- `section_color`:

  HS section color (e.g. '#74c0e2')

## Source

Open Trade Statistics
